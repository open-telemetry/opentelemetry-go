# Trace API

[![PkgGoDev](https://pkg.go.dev/badge/go.opentelemetry.io/otel/trace)](https://pkg.go.dev/go.opentelemetry.io/otel/trace)

The Trace API defines `trace.Span` and the interfaces applications use to record spans. To run it, set up the Trace SDK: see [sdk/trace](https://pkg.go.dev/go.opentelemetry.io/otel/sdk/trace), [trace.Span](https://pkg.go.dev/go.opentelemetry.io/otel/trace#Span), and the [Go instrumentation guide](https://opentelemetry.io/docs/languages/go/instrumentation/).
