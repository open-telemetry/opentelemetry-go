# OTLP Metric HTTP Exporter

[![PkgGoDev](https://pkg.go.dev/badge/go.opentelemetry.io/otel/exporters/otlp/otlpmetric/otlpmetrichttp)](https://pkg.go.dev/go.opentelemetry.io/otel/exporters/otlp/otlpmetric/otlpmetrichttp)

Package `otlpmetrichttp` exports OpenTelemetry metrics over HTTP using the
OTLP protocol.
See the [package example] for getting started and the [package overview]
for configuration options.
For a gRPC alternative, see the sibling [otlpmetricgrpc] exporter.
