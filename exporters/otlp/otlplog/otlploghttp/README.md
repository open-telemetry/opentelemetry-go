# OTLP Log HTTP Exporter

[![PkgGoDev](https://pkg.go.dev/badge/go.opentelemetry.io/otel/exporters/otlp/otlplog/otlploghttp)](https://pkg.go.dev/go.opentelemetry.io/otel/exporters/otlp/otlplog/otlploghttp)

Package `otlploghttp` exports OpenTelemetry log records over HTTP using the
OTLP protocol.
See the [package example] for getting started and the [package overview]
for configuration options.
For a gRPC alternative, see the sibling [otlploggrpc] exporter.
