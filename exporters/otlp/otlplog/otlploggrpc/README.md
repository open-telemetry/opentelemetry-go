# OTLP Log gRPC Exporter

[![PkgGoDev](https://pkg.go.dev/badge/go.opentelemetry.io/otel/exporters/otlp/otlplog/otlploggrpc)](https://pkg.go.dev/go.opentelemetry.io/otel/exporters/otlp/otlplog/otlploggrpc)

Package `otlploggrpc` exports OpenTelemetry log records over gRPC using the
OTLP protocol.
See the [package example] for getting started and the [package overview]
for configuration options.
For an HTTP alternative, see the sibling [otlploghttp] exporter.
